Avisé : comment marche le site

Le site est hébergé gratuitement sur GitHub Pages, à l'adresse avise-paris.github.io. Claude le met à jour pour toi.

L'espace client

  • Chaque client se connecte avec un identifiant (par exemple dolce-vita) et un mot de passe.
  • Son rapport est stocké sur le site sous forme chiffrée (AES-256). Sans le bon mot de passe, le fichier est illisible, même en fouillant le code du site.
  • Aucun service externe, aucune base de données, rien à payer.
  • Compte de démonstration : identifiant demo, mot de passe avise2026.

Ajouter un client

  1. Donne à Claude le nom du commerce et son lien d'avis Google.
  2. Claude crée son identifiant, son mot de passe, son espace chiffré et sa page de lien /r/nom-du-commerce pour la puce NFC.
  3. Note le mot de passe dans un endroit sûr à toi, puis donne l'identifiant et le mot de passe au patron, sur papier ou par SMS.

Chaque fin de mois

  1. Relève sur la fiche Google du client : la note, le nombre total d'avis, les nouveaux avis, le pourcentage de réponses, les publications, les photos, les signalements. Relève aussi la note et le nombre d'avis de ses concurrents.
  2. Envoie tout ça à Claude, avec 2 ou 3 réponses que tu veux mettre en avant.
  3. Claude met à jour le rapport chiffré du client et écrit « Le mot d'Avisé ». Le patron le voit en se connectant et peut l'imprimer en PDF.

Mot de passe oublié

Le patron t'appelle. Demande à Claude un nouveau mot de passe pour ce client : l'ancien ne marche plus dès la mise à jour.

Le formulaire d'audit

Les demandes d'audit du site arrivent dans la boîte avise.paris.12@gmail.com (via FormSubmit, gratuit et sans compte).
