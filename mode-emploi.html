Avisé : mise en ligne du site et de l'espace client

Tout est gratuit pour démarrer. Compte environ 1 heure la première fois.

Ce que contient ce dossier

Fichier Rôle

Tant que config.js contient des XXXX, l'espace tourne en mode démo, avec des données d'exemple.

1. La base de données (Supabase)

  1. Crée un compte sur supabase.com, puis « New project ». Choisis une région en Europe (par exemple Paris ou Francfort).
  2. Ouvre « SQL Editor », puis « New query ». Colle tout le fichier supabase/schema.sql, en remplaçant d'abord TON_EMAIL@exemple.fr par ton e-mail. Clique sur « Run ».
  3. Dans « Authentication », puis « Sign In / Providers », vérifie que la connexion par e-mail est activée. Désactive « Allow new users to sign up » : seuls les clients que tu invites peuvent avoir un compte.
  4. Dans « Authentication », puis « Users », clique sur « Add user ». Crée ton compte avec ton e-mail (le même que dans le SQL) et un mot de passe.
  5. Dans « Project Settings », puis « API », copie « Project URL » et la clé « anon public » dans espace/config.js. Ne colle jamais la clé « service_role ».

À savoir : sur l'offre gratuite, Supabase met le projet en pause s'il n'y a presque aucune activité pendant une semaine. Tes connexions à l'admin chaque semaine suffisent à l'éviter. S'il se met en pause, un bouton « Resume project » le relance sans perte de données. Quand tu auras plusieurs clients, l'offre Pro (25 $ par mois) supprime ces pauses.

2. La mise en ligne (Cloudflare Pages)

On n'utilise pas l'offre gratuite de Vercel : elle est réservée à un usage personnel et non commercial.

  1. Crée un compte sur cloudflare.com, puis va dans « Workers & Pages », « Create », « Pages », « Upload assets ».
  2. Glisse le dossier entier, et nomme le projet avise. Le site est alors en ligne sur avise.pages.dev.
  3. Pour avoir ton propre nom de domaine : achète-le (environ 10 € par an, par exemple avise.fr s'il est libre), puis ajoute-le dans « Custom domains ».
  4. Dans Supabase, va dans « Authentication », puis « URL Configuration ». Mets ton adresse (par exemple https://avise.fr) dans « Site URL » et ajoute https://avise.fr/espace/ dans « Redirect URLs ». C'est ce qui fait marcher « Mot de passe oublié ».

3. Le formulaire d'audit (Formspree)

  1. Crée un compte gratuit sur formspree.io, puis un nouveau formulaire. Copie l'adresse https://formspree.io/f/….
  2. Dans index.html, colle-la dans const FORM_ENDPOINT="";, puis remets le site en ligne. Les demandes d'audit arrivent alors dans ta boîte mail.

4. Ajouter un client

  1. Dans /espace/admin.html, remplis « Nouveau client » : le nom, la ville, l'e-mail du patron et la formule.
  2. Dans Supabase, va dans « Authentication », puis « Users », et clique sur « Invite user » avec le même e-mail. Le patron reçoit un lien pour choisir son mot de passe.
  3. Ajoute son lien de carte dans _redirects, sur une ligne /r/nom-du-resto lien-google 302, puis remets le site en ligne. Programme ses cartes NFC avec https://avise.fr/r/nom-du-resto.

5. Chaque fin de mois

  1. Dans l'admin, ouvre le client et clique sur « + Nouveau mois ». Les concurrents du mois précédent sont recopiés automatiquement.
  2. Remplis les chiffres relevés sur la fiche Google : note, nombre total d'avis, nouveaux avis, % de réponses, publications, photos, signalements.
  3. Mets à jour la note et le nombre d'avis des concurrents.
  4. Écris « Le mot d'Avisé » en 2 ou 3 phrases (je peux te le rédiger à partir des chiffres).
  5. Ajoute 2 ou 3 réponses mises en avant, avec seulement le prénom et l'initiale de l'auteur, et un extrait court de l'avis.
  6. Coche « Publié » et enregistre. Le patron voit son rapport, qu'il peut aussi imprimer en PDF.

Sécurité

  • Chaque patron ne voit que les établissements liés à son e-mail, et seulement les rapports publiés. Ce sont les règles de la base de données qui l'imposent, pas l'affichage.
  • Seuls les e-mails de la table admins peuvent modifier quoi que ce soit.
  • Pour ajouter un associé comme administrateur : insert into admins (email) values ('son@email.fr');
